# Voicebot Frontend

Simple React/Vite voicebot frontend.

## Setup

```bash
npm install
```

## Run

```bash
npm run dev
```

Open:

```text
http://localhost:5174
```

By default it calls:

```text
http://localhost:3000/chat
```

For a deployed backend, create `.env`:

```env
VITE_BACKEND_URL=https://your-backend.onrender.com
```
